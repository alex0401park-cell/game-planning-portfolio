# AI 매쓰플래너 — 서비스 기획·발표·마케팅

혼자 공부하는 학생이 오답 원인을 파악하고 다음 학습으로 이어갈 수 있도록 돕는 AI 학습 관리 서비스입니다. AI 창업 동아리 ainha의 5인 프로젝트로, 저는 서비스 기획·기능 구성·발표·마케팅 방향을 담당했습니다.

## 기획 내용

학생별 학습 루틴, 오답 원인 분석, 맞춤 학습 지원과 리마인드를 연결하는 서비스를 구상했습니다. 팀 발표 자료에는 Dual RAG 개념·전략 매칭, n8n 자동화와 학습 리포트 등이 제시되어 있습니다. 해당 기술의 전체 구현을 개인 개발 실적으로 주장하지 않습니다.

학습 타이머·플래너·모의고사 종 알림을 무료 입문 기능으로 제공하는 확장안을 정리했습니다. 학생 구독과 학원·교사 라이선스를 구분하고, 활성 이용·유료 전환·유지율로 효과를 확인하는 방향을 제안했습니다. 이는 기획안이며 실측 매출·사용자 증가 성과는 아닙니다.
